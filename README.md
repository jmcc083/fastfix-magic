# Clones Tech — Static Netlify Version

This version deliberately removes TanStack Start, Nitro, SSR and server functions. It is a standard React + Vite static site.

## Netlify
- Build command: `npm run build`
- Publish directory: `dist`
- Node: 22

The repository-level `netlify.toml` already supplies those values.

## Important
Replace the entire old GitHub repository contents with this project. Do not keep the old root `server.ts`, TanStack route files, `.lovable`, or old `netlify.toml`.
